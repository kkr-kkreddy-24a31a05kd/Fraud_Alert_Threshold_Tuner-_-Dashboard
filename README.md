# Fraud_Alert_Threshold_Tuner-_-Dashboard
Fraud_Alert_Threshold_Tuner_Dashboard
🛡️ AI-Powered Real-Time Fraud Detection System
A professional fraud detection dashboard that helps financial institutions dynamically tune fraud detection thresholds with explainable AI insights.

✨ Features
Core Features
Dynamic Threshold Tuning - Real-time adjustment of fraud detection sensitivity (0.0 to 1.0)
Live Performance Metrics - Precision, Recall, F1 Score, Accuracy update instantly
Explainable AI (XAI) - SHAP-based explanations for every transaction
What-If Analysis - Simulate different thresholds before deployment
Auto-Tune Feature - AI finds optimal threshold automatically
Advanced Features
📊 Multiple Export Formats - CSV, Excel, PDF reports
🌙 Dark/Light Mode - Toggle between themes
🔍 Advanced Filtering - Search by ID, amount, risk level, date range
⌨️ Keyboard Shortcuts - Arrow keys for threshold adjustment
💰 ROI Calculator - Financial impact analysis
🔔 High-Risk Alerts - Visual and audio notifications
🛠️ Tech Stack
Category	Technology
Backend	Python, Flask
Frontend	HTML5, CSS3, JavaScript, Bootstrap 5
Charts	Plotly, Chart.js
ML Model	XGBoost, Scikit-learn
Explainability	SHAP
Database	SQLite
📋 Installation
Prerequisites
Python 3.8 or higher
pip package manager
Steps
Clone the repository
git clone https://github.com/24A31A05KP/Fraud_Alert_Threshold_Tuner_Dashboard.git
cd Fraud_Alert_Threshold_Tuner_Dashboard
Install dependencies
pip install -r requirements.txt
Run the application
python app.py
Open your browser
http://localhost:5000
🎮 How to Use
Basic Controls
Adjust Threshold - Drag the slider or use ← → arrow keys
Select Presets - Click 0.3, 0.5, 0.7, or 0.9 for quick settings
Auto-Tune - Click button to let AI find optimal threshold
View Explanations - Click any transaction for AI analysis
